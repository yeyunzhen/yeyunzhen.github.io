    Drumset art

    约 3078 个字 预计阅读时间 10 分钟

    Explore 套鼓

    • 底鼓（bass drum BD），低音很重。主节奏低频。
    • 军鼓（snare drum SD），最薄，声音穿透力最强。主节奏中频。与底鼓互动形成稳定主节奏。在音乐薄弱位置，可以用敲击鼓边代替，产生弱一点的噪音。
    • 嗵嗵鼓（tom drum TD），一般有三个。一般用来特殊位置加花。一般嗵嗵鼓出现，不会有hihat。因为鼓手只有两只手。凡是实体乐器一定要符合实际演奏逻辑。
    • 踩镲（hihat HH）。四种音色：1，脚踩，两镲合击 2 闭和敲击 延音短3 开放敲击 延音长 4 半开镲。主节奏高频。
    • 吊镲 （crash cymbal Cy）：鼓棒棒身磕镲片边缘，有爆发力
    • 叮叮镲（ride cymbal Ry）:鼓棒鼓槌点镲面，延音长，高频氛围感觉。或者鼓槌点中心点，更脆。不同的鼓或镲片一般越大，音调更低，更加浑厚。
    • 两个鼓棒互相敲击也可以作为一种音色

    Edit 编辑

    以 REAL MACHINE 中的 Tape 808 Dry 为例

    • OH Head：鼓附近的立体声。稍微增大会拾取到鼓周围的声音，比如混响
    • Room Level：房间里的立体声。稍微增大会失去房间里的声音，比如混响
    • Beater：拾取鼓槌打击的声音。稍微增大beater会使得打击感更加明显。过分大会导致打击的声音过大，影响鼓原本拾取的声音。
    • Response Sample：限制采样的位置。降低上限，将不会超过敲击上限的位置，下限同理。
    • Response Volumn：Volumn越大，动态越大。小的越小，大的越大。Volumn越小，动态越小，越均衡。
    • Response Filter：Filter越大，轻打时的高频减少越明显。
    • Pitch：全局固定调音调，从头到尾一个音高，不会随时间变化。
    • Pitch Envelope：控制音尾收缩的程度，随时间自动变音调。
    • Volumn Envelope：音量变化全过程控制器

    一个例子：SNARE | 14x5.5", DW Craviotto

    SNARE | 14x5.5", DW Craviotto

    • 含义：当前加载的军鼓型号（DW 高端实木腔军鼓，尺寸 14 寸直径、5.5 寸深度），决定底子音色：偏浑厚复古摇滚质感
    • 调节时机：想更换军鼓腔体材质、尺寸、品牌时，去上方【KIT】页面切换鼓组预设，EDIT 页无法改硬件型号

    左侧旋钮：

    1. OH Level：吊顶话筒音量（Overhead）

      • 含义：整套鼓上方悬挂话筒收录的军鼓空间音色，带来整体鼓组融合感、镲片泛音
      • 调节：数值越大，军鼓越融入整套鼓、氛围感越强；调小 = 军鼓更干、贴耳紧实。摇滚一般拉至 30%~60%

    2. Room Level：房间环境话筒音量

      • 含义：远距离房间收音，大空间混响氛围，增加纵深、厅堂氛围感
      • 调节：流行 / 轻摇滚少加（10%-30%）；摇滚、金属拉满一点，做大空间厚重感

    二、右上区域：KIT PIECE CONTROLS 鼓件动态核心控制区（Response/Pitch/ 包络）

    1. RESPONSE 动态响应（控制敲击力度反馈）

    • Volume：整体音量增益 / 衰减

      作用：军鼓整体响度微调；敲击轻 / 重整体音量统一增减

      调节：峰值过大就拉低，音量偏小略微推高 - Vel.（Velocity 力度灵敏度）

      含义：MIDI 音符力度对应音量的灵敏度

      调高：轻敲声音很轻、重敲爆发力极强（动态大，适合真人鼓手细腻演奏）

      调低：强弱敲击音量差距变小（动态压缩，适合电子、lo-fi、说唱，力度整齐划一）

      你的预设是 lo-fi 风格，建议适中偏低

    2. PITCH 音高 / 音调调节

    • Main：军鼓整体音高（最常用）

      往右拧 = 音调升高→军鼓更脆、明亮、短促（流行、朋克）

      往左拧 = 音调降低→鼓腔更深、低沉浑厚（摇滚、布鲁斯） - OH/Room：只改变 OH 吊顶 + Room 房间音的音调，不碰军鼓干声

      极少调节，仅用来微调空间泛音和军鼓本体音调契合度 - Offset：采样偏移（毫秒）

      含义：波形启动时间偏移，微调军鼓起音快慢、相位

      ✅ 关键：搭配军鼓上下皮采样时，微小偏移可改善相位抵消，一般 0ms 不动即可

    3. PITCH ENVELOPE 音调包络（音高随时间变化曲线）

    横轴：时间 ms；纵轴：音调高低

    曲线形态：敲击瞬间音调先上扬再回落

    • Start：起始音高
    • Hold：保持时长

    • Release：音高回落速度

      调节场景：

      想要敲击瞬间 “啪” 一下的上扬脆感：拉高起点、缩短保持时间；

      想要低沉平缓复古音色：拉平曲线，弱化音高起伏

    Vel 旋钮数值调节逻辑

    1. Vel = 0（完全关闭力度关联）

      无论你用多轻 / 多重力度打军鼓，音调起伏曲线永远一模一样，音高变化完全固定，不受敲击力度影响。

      适合：Lo-Fi、嘻哈、电子音乐（想要统一呆板音色，无动态差异）

    2. Vel 往右加大（数值越高）

      力度对音调的干预越强：

    3. 大力敲击：开头音高飙升更剧烈，脆感、冲击感拉满

    4. 轻柔敲击：音调上扬几乎消失，声音温润下沉

      适合：摇滚、爵士、真人现场写实鼓，还原鼓手轻重敲击的细微音色差别

    4. VOLUME ENVELOPE 音量包络（决定军鼓完整形态，混音最核心）

    横轴时间，纵轴音量，你的曲线是标准短促军鼓形态：

    1. Attack 起音（0ms）：敲击瞬间冲击出现速度

      0ms：瞬态极强、敲击硬朗有力；拉高 Attack（5~20ms）：弱化硬冲击，变柔和圆润（爵士、舒缓曲风） 2. Decay 衰减（5.0ms）：音量从峰值往下掉的速度

      数值小：衰减快→军鼓短促、干净不拖沓（流行、说唱）

      数值大：衰减慢→鼓腔延音更长、浑厚饱满（摇滚、复古） 3. Sus.Lev. 持续电平：衰减结束后稳定的剩余音量 4. Sus.Time 持续时长：稳定音量维持多久 5. Release 释放：最后彻底静音速度

      Lo-fi 曲风：短 Decay、短 Release，干净短促；复古摇滚拉长 Decay 增加腔体共鸣

    三、左下 INSERT FX 插入效果器链（军鼓专属通道效果，从上至下：Noise 噪音→压缩→EQ→磁带塑形）

    1. Snare Buzz / Top & Bottom 军鼓腔体噪音控制

    • Decay：军鼓皮震动的沙音、簧片噪音（响弦噪音）衰减时长

      调高：簧片沙沙声持续更久，复古氛围感强；调低：静音干净，现代流行风格 - Level：簧片噪音总音量

      朋克、乡村多开；电子乐、极简流行适当压低噪音

    2. COMP & DIST 压缩 + 失真模块（压缩在前，失真在后）

    COMP 压缩器（控制动态、收紧军鼓响度）

    旋钮含义：

    • Thr（Threshold 阈值）：触发压缩的音量门槛

      往下拉阈值：更容易触发压缩，动态被收紧，大小敲击音量趋于一致 - Ratio 压缩比：压缩强度

      1.5:1~2:1 轻微压缩（保留动态）；3:1~5:1 中度压缩（流行摇滚标配）；大于 6:1 重度压缩（lo-fi、电子整齐音色） - Attack 压缩启动时间

      短 Attack：刚敲击瞬间就压缩，削弱军鼓硬冲击；

      长 Attack（10~30ms）：保留前端清脆敲击瞬态，再压缩后半段共鸣（军鼓首选） - Release 释放时间：压缩结束回弹速度

      快释放：每一次敲击都回弹干净；慢释放：粘连感、浑厚一体感 - GR（Gain Reduction）：压缩量指示灯，看被压缩了多少 dB

    DIST 失真模块（Heavy 模式硬失真）

    • Focus：失真频段聚焦（侧重低频失真还是高频毛刺）
    • Amount：失真总量

    • Mix：干湿比例（干声 + 失真声混合）

      调节：摇滚加一点点失真增加毛刺穿透力；lo-fi 适量增加饱和失真；干净流行基本关闭

    3. EQ 四段参数均衡器（你截图里调好的均衡曲线）

    四个频点逐个解释 + 军鼓常规用法：

    1. 89.5Hz Q0.2 0dB：超低频

      作用：军鼓底部超低频共鸣，0dB 没增减；想厚重就 + 2~4dB，浑浊就削减 2. 110Hz Q0.4 -1.36dB：低频腔体（军鼓浑厚根基）

      小幅衰减：避免和底鼓 60-120Hz 低频打架，防止整体混音低频臃肿（混音必备操作） 3. 167Hz Q2.5 +4.5dB：中低频丰满度

      提升这里：军鼓变得圆润饱满，鼓腔厚度拉满，复古摇滚最爱增益区间 4. 3.96kHz Q0.71 基准点、7.24kHz Q0.2 +2.3dB、5.02kHz：高频通透刺耳区

      3~8kHz 提升：增加军鼓清脆敲击感、穿透力，耳机音箱里更突出；过量提升会尖锐刺耳

    4. TAPE & SHAPE 磁带饱和 + 波形塑形（Lo-fi 灵魂模块）

    TAPE 磁带机饱和失真（模拟老式磁带录制温暖糊感）

    • Drive：磁带驱动饱和量，越大越暖、谐波越多、细节轻微模糊（lo-fi 核心调节旋钮）
    • Bottom：低频磁带加厚，增加松软低频
    • Sustain：延音拉长

    SHAPE 波形塑形 / SAT 饱和塑形

    改变波形形态，压缩峰值，做出复古圆润质感，电子、低保真曲风常用轻微开启

    右侧 Trim：效果链整体输出音量补偿，压缩饱和后音量下降就推高 Trim 补响度

    四、最下方：全局调音台推子区域（整组鼓通道总线）

    横向一排通道推子：KICK 底鼓、SNARE 军鼓、踩镲、通通鼓、OH 吊顶、Room 房间、BUS 编组、SEND FX 发送效果

    单通道竖列按钮（每一列都统一）

    从上到下：

    1. M 按键 = Mute 静音：点击单独静音这条轨道
    2. S 按键 = Solo 独奏：只播放当前轨道，排查音色、相位问题必用
    3. 长条竖推子：通道音量推子，控制该声部总输出音量

    4. 底部上下箭头：通道相位反转键 Φ（Phase Invert）

      ✅ 重点（对应你之前问的相位）：

      军鼓分 Top 上皮 / Bottom 下皮双采样叠加时：

      选中 Bottom 下皮轨道，点击下方相位箭头，反转 180° 相位，消除上下皮相位抵消，军鼓低频更扎实浑厚

      使用步骤：Solo 独奏上下两层，反复开关相位键对比听音质

    SEND FX 发送效果轨

    FX1 / FX2：发送混响、延迟效果量

    • Level：发送到混响的音量大小

      想要军鼓带空间混响，就拉高 Send 旋钮；干声军鼓拉到 0 即可

    MASTER 总输出推子

    整套鼓组最终总音量输出，避免整体音量爆音过载

    五、分曲风通用调节流程（照着调即可）

    1. Lo-fi / 嘻哈（你当前预设风格）

    1. 音量包络：短 Attack、短 Decay，军鼓短促利落
    2. 压缩：中等压缩比，压低动态，敲击力度整齐
    3. EQ：削减 100Hz 左右低频防臃肿，小幅提升 4~7kHz 增加清脆感
    4. 磁带 TAPE 适量 Drive，增加复古暖糊质感
    5. 上下皮叠加：下皮轨道开启相位反转
    6. Room 房间音量适中，营造慵懒空间氛围

    2. 经典摇滚 / 布鲁斯

    1. Pitch 略微降一点，音调偏低沉浑厚
    2. 拉长 Decay 延音，鼓腔共鸣更久
    3. 压缩长 Attack 保留瞬态，轻微失真增加毛刺
    4. 大幅提升 150~200Hz 中低频打造厚度
    5. OH+Room 音量拉高，整体鼓组氛围感宏大

    3. 流行抒情 / 轻民谣

    1. 关闭失真、磁带饱和
    2. 极轻微压缩，保留动态起伏
    3. EQ 高频小幅提亮，低频干净削减多余共鸣
    4. 极小房间混响，军鼓干净贴耳

    六、日常调节顺序（标准调校步骤）

    1. 先定音高 Pitch + 音量包络（决定军鼓基础长短、高低音色）
    2. 开启上下皮采样，相位对齐（核心第一步）
    3. 压缩收紧动态
    4. EQ 修整高低频，规避和底鼓频段冲突
    5. 磁带 / 失真做风格染色
    6. 最后加空间 OH、Room、混响发送，融入整套鼓组
